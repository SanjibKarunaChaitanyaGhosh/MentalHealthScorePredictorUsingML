Phase 01

Machine Learning Model Build

Explore

  • Load data, check shape & columns
  • Types, missing values, duplicates
  • EDA: target, heatmap, key relationships

Prepare

  • Clean duplicates & invalid values
  • Fix skew with a log-transform
  • Group rare categories into “Other”
  • Split before preprocessing

Model

  • ColumnTransformer + Pipeline
  • Baseline, then stronger model
  • Tune with RandomizedSearchCV
  • Save with joblib.dump()
Why it matters: saving the whole pipeline means the API calls predict() on raw input, with no preprocessing to reimplement.
Phase 02

FastAPI Service Layer

import joblib
from fastapi import FastAPI

app = FastAPI()
model = joblib.load("model.pkl")  # once

@app.post("/predict")
def predict(data: Input): ...

@app.get("/health")
def health(): return {"ok": True}
  • Load model.pkl once at startup
  • /predict POST route
  • /health for uptime checks
  • Serve the static frontend from the same app
Gotcha: same origin means no CORS to configure.
Phase 03

Pydantic Validation

from pydantic import BaseModel, Field

class Input(BaseModel):
    age: int = Field(ge=0, le=120)
    sleep_hours: float = Field(ge=0, le=24)
    # one typed field per model input

class Output(BaseModel):
    prediction: float
  • One typed field per model input
  • Constraints reject bad values automatically
  • Response schema for the output
  • Both wired into /predict
Demo moment: send a negative age and show the auto-generated 422 error.

Phase 05

Deployment on Render

  • Push the repo to GitHub
  • New Web Service, connect the repo
  • Build: pip install -r requirements.txt
  • Start command uses $PORT, never a hardcoded port
Free tier note: the service sleeps when idle, so the first request can take 30–50s. Mention this before a live demo so it doesn’t look broken.
